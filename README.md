# LemmonPinPy

LemmonPinPy is my first pinball machine setup.
It is built on RaspberryPi, Fast Pinball hardware, and Mission Pinball Framework

To get started:
```bash
git clone https://github.com/gusgus84/LemmonPinPy.git
python -m venv .venv
bin/pip install mpf --pre
```
